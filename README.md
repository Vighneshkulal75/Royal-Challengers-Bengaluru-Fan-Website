# 🏏 Royal Challengers Bengaluru – Fan Website

A responsive RCB fan website built with HTML, CSS and JavaScript.

🔗 **Live Demo:** [royal-challengers-bengaluru-fan-web.vercel.app](https://royal-challengers-bengaluru-fan-web.vercel.app)

## Features
- Responsive design with a mobile menu
- Men's / Women's squad with role filters
- IPL 2025 fixtures and results
- RCB videos, news and merchandise

## Tech Stack
HTML5 · CSS3 · JavaScript · Vercel

## Run Locally
```bash
git clone https://github.com/Vighneshkulal75/Royal-Challengers-Bengaluru-Fan-Website.git
cd Royal-Challengers-Bengaluru-Fan-Website
python -m http.server 8000
```
Open `http://localhost:8000`
